MODEL & PROVENANCE

A new observer. The same photograph.

Shared input makes inspection familiar. The policy, memory and trajectories come from the independent Python project.

01 / PERCEPTION

Foveated RGB only

The observer receives a gaze-dependent blurred image. Centrally gated SSDLite semantic detections, coarse color components and a spatial grid propose locations. A foveated context crop supplies context, but only central labels and clipped observed boxes enter memory. No full-image semantic detector bank is supplied.

The center circle is a pixel-based approximation: 7.5% of image width. It is not a calibrated retinal field.

02 / MEMORY & CHOICE

Explicit, uncertain beliefs

Object association combines position, appearance and category support. Beliefs decay; central visits strengthen familiarity. The policy balances salience, task/context, novelty, expected uncertainty reduction, movement/observation cost and soft revisit history. The old uncertainty × novelty proxy remains available as a baseline. Longer observation improves evidence only up to the sensory ceiling; low-value stays are suppressed.

Spatial weights remain interpretable heuristics. Only the three timing variants have been fitted on the internal training split and compared on validation and test splits.

03 / THIS DEMONSTRATION

Prepared runs from Python

Prepared starts use seed 42 and the viewing/fixation budgets recorded in the manifest. Stay entries are additional observation segments, merged into fixations for empirical evaluation. All scores and memory states are generated by the Python implementation. The browser replays them and reconstructs no additional perceptions.

Pinned MiDaS Small supplies relative inverse depth. Only central observed surface samples update object memory. No metric scale, complete physical reconstruction, head movement or blink behavior is inferred.

Photograph and scientific scope

The Porto perspective photograph comes from the Salient360! toolbox panorama and is the same RGB input previously shown in Gaze Lab. Only the photograph is shared; prior detections, depth, scanpaths, model code and benchmark results are not used.

The toolbox repository has an MIT license; the example stimulus has no separately documented license. The photograph is shown here as a private research demonstration. Human panorama-viewing recordings are not matched to this perspective crop.
