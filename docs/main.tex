% ABSTRACT
% ============================================================================
\begin{abstract}
This paper presents implementations of three fundamental image rectification techniques in computer vision: projective rectification, affine rectification, and metric reconstruction. Projective rectification eliminates perspective distortion by computing the vanishing line from a rectangular object and mapping it to infinity, demonstrated on a flat-screen television image. Affine rectification restores parallelism using two pairs of parallel lines to identify the vanishing line, applied to an interior wall photograph with doorway and window features. This method employs an alternative but mathematically equivalent approach to the orthogonal line pairs method, using vanishing point computation for improved robustness. Metric reconstruction uses Direct Linear Transform (DLT) to compute a planar homography between image and world coordinates. Proper train/test validation on a 40.16×40.16 inch artwork poster demonstrates perfect reconstruction on four training corner points (0.000 inch error) and realistic generalization on four independent test points at edge midpoints (3.337 inch mean error, 8.31\% relative error). The 8.31\% test error is consistent with literature values for uncalibrated single-view metrology and reflects combined effects of point selection precision, lens distortion, and planar approximation. These implementations demonstrate that classical projective geometry methods remain effective for practical rectification tasks, with applications in architectural photography correction, document scanning, augmented reality, and real-world measurement from images.
\end{abstract}
